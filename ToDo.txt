Add a centralized keyboard shortcut system to SimpleFile.

## Context
SimpleFile is a Tauri + Svelte 5 + Rust (Windows-only) desktop file manager.
The frontend is in `frontend/src/` with Svelte components in
`frontend/src/lib/components/` and workflow orchestration in
`frontend/src/lib/app/`. Typed Tauri commands are in
`frontend/src/lib/tauri.ts`. Shared app state lives in
`frontend/src/lib/appState.ts`. Runtime state is in
`frontend/src/vanilla-js/runtime/state.svelte.js`. The Rust backend is in
`src-tauri/src/`. Settings are persisted through the db module
(`src-tauri/src/db.rs`) via `get_db_setting` / `set_db_setting` commands.

## Requirements

1. Create `frontend/src/lib/keyboardShortcuts.ts` that exports:
   - A `ShortcutRegistry` that maps shortcut identifiers to key combos
     (modifier+key strings like `"Ctrl+C"`, `"F2"`, `"Alt+Up"`).
   - A `registerShortcut(id, defaultCombo, handler)` function.
   - A `handleKeyDown(event: KeyboardEvent)` dispatcher that matches the
     pressed key combo against registered shortcuts and calls the handler,
     respecting focus context (don't fire file shortcuts when an input or
     textarea is focused).
   - An `unregisterShortcut(id)` function for cleanup.
   - A `getShortcutMap()` function returning the current id-to-combo map for
     UI display.

2. Register these default shortcuts by wiring them to existing
   frontend actions and Tauri commands:
   - `F2` → Rename selected item (`rename_entry`)
   - `Delete` → Move to trash (`move_to_trash`)
   - `Shift+Delete` → Permanent delete (`delete_entry`)
   - `Ctrl+C` → Copy to clipboard (store source paths in transfer clipboard
     at `frontend/src/lib/transferClipboard.ts`)
   - `Ctrl+X` → Cut to clipboard
   - `Ctrl+V` → Paste from clipboard (trigger copy or move via
     `transferWorkflow.ts`)
   - `Ctrl+A` → Select all items in current directory
   - `Ctrl+Shift+N` → New folder (`create_directory`)
   - `Ctrl+N` → New file (`create_file`)
   - `F5` → Refresh current directory (re-invoke `list_directory`)
   - `Ctrl+L` or `Alt+D` → Focus the path/address bar input
   - `Alt+Up` → Navigate to parent directory
   - `Alt+Left` → Navigate back in history
   - `Alt+Right` → Navigate forward in history
   - `Ctrl+T` → New tab
   - `Ctrl+W` → Close current tab
   - `Ctrl+Tab` → Next tab
   - `Ctrl+Shift+Tab` → Previous tab
   - `Enter` → Open selected item (navigate if directory, open if file)
   - `Ctrl+Shift+C` → Copy full path of selected item to system clipboard
   - `Space` → Toggle Quick Look preview for selected item
   - `Ctrl+F` → Focus the quick filter / search input
   - `Escape` → Close any open modal, overlay, or cancel current filter

3. Attach the global `keydown` listener in `App.svelte` or the layout shell
   component. Make sure it does not interfere with browser dev-tools shortcuts
   during `npm run dev`.

4. (Optional) Add a small "Keyboard Shortcuts" reference modal accessible from
   the app menu or `Ctrl+?` / `F1` that lists all active shortcuts in a
   two-column table (Action | Shortcut).

5. Do NOT add shortcut customization UI yet — just the registry with defaults
   and the dispatcher. Customization can be added later by persisting overrides
   via `set_db_setting`.

## Files to create or modify
- [NEW] `frontend/src/lib/keyboardShortcuts.ts`
- [MODIFY] `frontend/src/App.svelte` or layout shell — attach keydown listener
- [MODIFY] relevant component files to call existing actions through the
  shortcut handlers

## Verification
- `npm run check` must pass (svelte-check, vite build, all guard scripts).
- Pressing F2 with a file selected should trigger rename.
- Pressing Ctrl+L should focus the path bar.
- Pressing Alt+Up should navigate to the parent directory.
- Shortcuts must not fire when the user is typing in an input field.
- No regressions in existing functionality.
